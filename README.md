# DNS Speed Test

Android-приложение для проверки доступности и скорости ответа популярных публичных DNS-серверов.

<img src="https://img.shields.io/badge/platform-Android%207.0%2B-3ddc84" alt="Android 7.0+"> <img src="https://img.shields.io/badge/Kotlin-1.9.24-7f52ff" alt="Kotlin"> <img src="https://img.shields.io/badge/UI-Jetpack%20Compose%20%2B%20Material%203-1565c0" alt="Compose">

## Возможности

- **Реальные DNS-запросы.** Для каждого сервера отправляется настоящий DNS-запрос (A-запись `example.com`) по UDP на порт 53 и замеряется время до ответа — это честная проверка резолвинга, а не ICMP-ping.
- **14 популярных DNS-серверов** из коробки: Google Public DNS, Cloudflare, Quad9, OpenDNS, AdGuard DNS, CleanBrowsing, Comodo Secure DNS, Яндекс.DNS (основные и резервные адреса).
- **Свои DNS-серверы.** Можно добавить собственный адрес (например, домашний роутер или корпоративный резолвер) с валидацией IPv4/IPv6. Свои серверы сохраняются между запусками.
- **Сортировка по скорости.** После полного прогона таблица автоматически выстраивается от самого быстрого к самому медленному, недоступные серверы уходят вниз.
- **Параллельное тестирование** на корутинах — все серверы проверяются одновременно, интерфейс не блокируется.
- **Цветовая индикация:** зелёный `< 50 мс`, жёлтый `< 150 мс`, оранжевый — медленнее, красный — недоступен.
- Баннер с самым быстрым сервером, обновление всего списка и повторная проверка отдельного сервера.

## Стек

- Kotlin + Jetpack Compose, Material 3
- Kotlin Coroutines для параллельных сетевых замеров
- Ручная сборка DNS-пакета через `DatagramSocket` (без сторонних сетевых библиотек)
- minSdk 24 (Android 7.0), targetSdk 34

## Сборка

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для сборки нужны JDK 17+ и Android SDK (compileSdk 34, build-tools 34.0.0). Путь к SDK указывается в `local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

## Установка

Готовый APK можно скачать со страницы [Releases](../../releases). Debug-сборка подписана отладочным ключом, поэтому при установке потребуется разрешить установку из неизвестных источников.

## Как устроен замер

`DnsChecker` вручную собирает DNS-пакет: 12-байтовый заголовок со случайным ID и флагом рекурсивного запроса, затем QNAME из label-ов, `QTYPE=A`, `QCLASS=IN`. Пакет уходит по UDP на порт 53, время замеряется через `System.nanoTime()` от отправки до получения ответа. Ответ считается валидным, если совпал ID запроса и выставлен бит QR. Таймаут — 3 секунды.
